DataPluck: Web Scraper & JSONL Dataset Builder

Visual web scraper that runs entirely in the browser, with no backend of its own

Point at a list, table, feed or article, click once, and export clean CSV, Markdown, JSON or JSONL. It is built for anyone who needs structured data from a page, including training data for language models.

  1. 1. PickHover to preview a repeating group, click to lock it, widen or narrow the selection.
  2. 2. CleanRename columns, parse numbers, extract with regex, remove duplicates.
  3. 3. ExportDownload or copy CSV, Markdown, JSON, JSONL, or send to Sheets and Notion.
  • Detects repeating items and names columns from class names, headings and the shape of the value (price, date, rating).
  • Per-column cleaning: $1,299.00 and 1.299,00 € both become numbers, plus case changes, link domains, find and replace, and regex extraction.
  • Collects across up to 200 pages, through infinite scroll and virtualized lists, and restores an interrupted run.
  • Exports for fine-tuning and retrieval: OpenAI-style messages, Alpaca, ShareGPT, prompt/completion and chunked RAG records.
  • Adds source_url and captured_at columns so a dataset can be audited later.

No backend

Page content stays on the user’s computer unless they export it.

Narrow permissions

Asks for activeTab instead of all-sites access, and runs no script on pages the user did not click.

Safe exports

Cells that start with =, +, - or @ are escaped, so a scraped page cannot plant formulas in a CSV.

Tested in real Chromium

70+ unit and end-to-end tests, run with Playwright against fixture pages and a mock license server.
